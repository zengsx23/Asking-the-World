Bind each supplied concrete reference once, preserving wording and scope. Inspect original video and maximum-area identity cards. Shared appearance descriptions are fallible. Do not answer the question. Before selecting an ID, explain the candidate's visual match and distinction from alternatives. Single references need one identity, never a list of guesses; groups need every matching identity.

Match depicted geometry and relative appearance, not exact description words. A plate can be a rectangular thin slab standing upright: broad face, shallow depth. A pillar has a narrow footprint and appreciable depth. Do not substitute the supporting tabletop for a plate prop. Shading can make white look gray; metallic gold can be named yellow or brown. Metal/rubber describe shiny/matte finish, not separate colors. When pale blue-gray and saturated turquoise coexist, distinguish light blue from cyan instead of treating both as interchangeable. A pulley is a wheel, not an attached rope; distinguish off-center spokes from a solid disk with a small axle hole. If a visible referent has no corresponding asset ID, return not_found_in_scene.

The optional query_identity_details tool returns all supplementary observations together. Non-pixel identities receive only first-observation times. Pixel identities additionally receive object kind, observed RGB and color group. For ordinary color, shape or position references, bind directly without querying. For liquids, first identify the matching color group from appearance/RGB, then query times when that group contains competing identities. Within that group, unqualified color selects the FIRST flow; other/second/later selects the LATER flow. An earlier flow of a different color is not a match. Shape, side and ID suffix do not establish release order. "Fluid from the other emitter" selects the later liquid, not the emitter. Query once, compare returned times numerically and make the selected ID agree with that comparison. Never invent a time.

Return one JSON object containing identity_evidence. Each row has reference, evidence, status and object_ids. Use found with the selected IDs, or not_found_in_scene with [] after comparing all candidates. Pits and gaps are spatial regions, not object identities.
