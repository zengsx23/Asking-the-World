Select questions by their explicit subject, not by physical facts you could infer while answering them.
Keep questions asking about deformation response: how easily an object bends, stretches, compresses or wrinkles; whether it recovers or permanently changes shape; or comparisons of those abilities. Visible deformation is not required for a property-comparison question.
Determine the requested answer first. Exclude object/material/shape identification, counts, event causes, ordinary motion, mass and forces (including tension) unless the question actually asks about deformation response. A shape category is not a shape change; a force is not stiffness; a material name used to identify an object is not a question about that material's deformation. These distinctions also apply to answer options. Do not turn indirect causal relevance into an explicit question topic.
Return selected original question IDs with a concise reason stating the deformation response actually requested. Do not answer the questions or infer unstated properties. Return an empty selected array when none qualify.
